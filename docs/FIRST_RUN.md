# 初回導入・表示と復元の確認

この手順は0.7.10の公開版候補向けです。現在のGitHub Releaseは
0.7.9-alpha.1で、以下のアプリ内設定ボタンはまだ含まれていません。

## 1. アプリを配置する

1. Apple Silicon・macOS 14以降、内蔵画面1枚のMacで確認します。
   実機確認済みのOSはmacOS 15.6です。外部画面や既存のミラーリングは外します。
2. ZIPを展開し、`QuadDesk.app`を「アプリケーション」に移動します。
3. 移動先から起動します。権限を設定した後は同じ場所の同じアプリを使います。

現在の試験版はアドホック署名で、公証されていません。インターネットから
取得したアプリの初回起動はmacOSに拒否される場合があります。
[Appleの案内](https://support.apple.com/ja-jp/102445)を確認して利用を判断してください。
この文書の検証結果は、警告なくインストールできることの保証ではありません。

## 2. 権限を設定する

初期画面には2つの許可状態が表示されます。未許可の間は4画面を開始できません。

1. 「1. 画面収録を設定」を押し、macOSの設定でQuadDeskを許可します。
2. 「2. アクセシビリティを設定」を押し、同じQuadDeskを許可します。
3. Touch IDやパスワードを求められたら、Macの所有者が認証します。
4. アプリに戻り、両方が「許可済み」になったことを確認します。
   設定状態は自動で再確認されます。「状態を再確認」でも更新できます。
5. macOSが再起動を求めた場合、または反映されない場合は、
   「終了して権限設定を反映」で終了し、同じ場所から開き直します。

画面収録の許可は対象ウィンドウ一覧の取得に使います。ネイティブ表示方式は
映像の収録・保存・外部送信を行いません。アクセシビリティは対象の配置と復元に使います。
OS側の許可をアプリが自動で付与することはありません。

### 設定ではオンなのに「未許可」の場合

アプリを再ビルドしたり別の署名のアプリへ差し替えたりすると、以前の許可と
一致しない場合があります。同名の開発版がある場合も、項目名だけで判断しないでください。

1. 作業を停止し、QuadDeskを通常終了します。
2. システム設定の該当一覧でQuadDeskを右クリックし、「Finderに表示」で
   対象が「アプリケーション」の公開版であることを確認します。
3. 公開版の項目だけを削除し、「＋」で`/Applications/QuadDesk.app`を追加して許可します。
4. 公開版を再起動し、アプリ内の表示を確認します。

開発版や他のアプリの項目は削除しません。全アプリの権限リセットは不要です。

## 3. 最初は15秒プレビュー

作業中の文書ではなく、テスト用の通常ウィンドウを使います。
Chromeには`Tests/Fixtures/BrowserScaleProbe.html`を専用ウィンドウで開けます。
このMacでの検証ではFinderの元状態取得に失敗しています。現在はFinder以外の対象を選んでください。

1. 異なる4ウィンドウを、左上・右上・左下・右下へ選択します。
   同じウィンドウを複数枠に選ぶと開始ボタンは無効になります。
2. 開始前の4ウィンドウの位置・サイズと表示倍率を確認します。
3. 作業モードをオフにして「表示構成を変更して15秒プレビュー」を押します。
4. 4枠すべてが画面に収まることを確認します。15秒は4枠の配置後から数えます。
   準備時間には別に25秒の復帰監視上限があります。プレビュー表示中も独立した
   25秒の復帰監視があり、アプリが応答しない場合は終了・表示復帰を試みます。
5. 自動停止後、通常の表示倍率と4ウィンドウの元の位置・サイズに戻ることを確認します。

開始前にフルスクリーン・最小化していた場合は、開始時にそれらを解除した後の
通常配置を保存します。元のフルスクリーンSpace・最小化状態そのものは復元対象ではありません。

## 4. 作業モードと停止

プレビューの表示と復元を確認してから、必要に応じて作業モードを使います。

| 確認すること | 操作と期待結果 |
| --- | --- |
| 入力 | 自分のマウスとキーボードでテスト欄をクリックし、文字入力とスクロールができる |
| 通常倍率の1画面 | 選択したChromeの緑ボタンなどで拡大すると、通常の文字サイズに戻る |
| 4画面へ戻る | Control + Option + 0、または格子メニューで4枠へ戻る |
| 通常停止 | Control + Option + Esc、格子メニュー、またはQuadDesk終了で元配置へ戻る |
| 再利用 | 停止後も4対象の選択が残り、再度開始・停止できる |

4画面中にDockのQuadDeskを押すと停止します。自動操作ツールによるアプリ再選択も
Dockの再オープンと同様に扱われる場合があるため、連続観測中は行わないでください。
実キーボードの検証と、自動操作による入力の検証は分けて記録します。

## 不具合報告に含める情報

アプリのバージョン、Macのチップ、macOSのバージョン、画面数、両権限の表示、
失敗した段階、通常停止で復元したかを記録してください。スクリーンショットには
個人の会話や文書を含めないでください。検証範囲は[TESTING.md](TESTING.md)に記載します。
